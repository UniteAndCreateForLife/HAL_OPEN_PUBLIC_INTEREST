# Proposed six-month milestones

These are proposed deliverables, not completed work.

| Month | Deliverable | Evidence gate |
| --- | --- | --- |
| 1 | Finalize scope, governance, conflict disclosure, privacy/security baseline, and public inventory | approved decision records and reproducible test baseline |
| 2 | Harden local-route and provenance primitives against malformed input and concurrent use | focused tests, static checks, independent review |
| 3 | Add portable evaluation fixtures and a redacted knowledge-store interface | offline evaluation report and privacy review |
| 4 | Publish documentation, threat model, contributor workflow, and release automation | clean release candidate with secret/dependency scans |
| 5 | Run an external reproducibility review and address findings | reviewer report and rework receipt |
| 6 | Make the first public release and publish a transparent progress report | host approval, tagged release, hashes, and unresolved-risk list |

Each milestone must remain within the approved public-interest scope and must
not be used as a proxy for private HAL SUPREME product work.
