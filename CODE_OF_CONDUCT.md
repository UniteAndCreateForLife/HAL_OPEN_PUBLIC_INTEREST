# Code of Conduct

## Purpose

HAL Open Local AI is a public-interest software project. Participation should make the project safer, more inspectable, and more useful to people who want reproducible local/private AI infrastructure.

## Expected behavior

Participants are expected to:

- communicate respectfully and focus criticism on ideas, code, evidence, and observable behavior;
- welcome good-faith questions from people with different experience levels;
- document uncertainty and avoid presenting unverified claims as facts;
- protect privacy, credentials, personal data, private endpoints, and rights-restricted material;
- preserve the repository's evidence, provenance, and human-review boundaries;
- disclose relevant conflicts of interest when proposing work that could create financial or governance benefit;
- respect project scope, licensing, contribution rules, and maintainers' review decisions.

## Unacceptable behavior

The following are not acceptable:

- harassment, threats, discriminatory abuse, stalking, or deliberate intimidation;
- publishing another person's private information without clear authorization;
- credential theft, secret harvesting, prompt/session-context exfiltration, or attempts to bypass documented safety boundaries;
- knowingly submitting malicious code, hidden data collection, or deceptive provenance;
- impersonating maintainers, funders, fiscal hosts, institutions, or partner organizations;
- falsely claiming acceptance, funding, endorsement, certification, test results, or deployment status.

## Scope

This code applies to repository issues, pull requests, discussions, project-managed communication channels, and other spaces where someone is representing this project.

## Reporting

For ordinary project disagreements, use the relevant issue or pull request and keep the discussion technical and specific.

For conduct, privacy, or sensitive safety concerns that should not be public, use the private contact path at https://halsupreme.com and identify the message as concerning **HAL Open Local AI / HAL_OPEN_PUBLIC_INTEREST**. Do not post secrets, identity documents, or sensitive personal information in a public GitHub issue.

## Enforcement

Maintainers may edit or remove contributions, comments, or participation that violate this code; request corrective action; temporarily restrict participation; or permanently remove access from project-controlled spaces when warranted.

Enforcement decisions should be proportionate, documented privately when sensitive, and should not override applicable platform rules or law.

## Project boundary

This code governs participation in this public repository. It does not create employment, fiscal sponsorship, funding, partnership, legal representation, or authority over the separate HAL SUPREME system.
